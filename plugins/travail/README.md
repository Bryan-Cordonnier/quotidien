# Travail

Plugin pour [Etable](https://github.com/etable-project/etable) (distribution Quotidien) : vos contrats et vos paies (intérim et ses agences, réserve, CDD, CDI). Dit **combien** on sera payé et **quand** ; c'est Budget qui estime ce qui reste. Budget, Finances et l'Agenda sont facultatifs.
Spécification : [docs/24](../../etable/docs/24-spec-plugins-budget.md) et [docs/29](../../etable/docs/29-argent-finances-travail.md).

```bash
npm test -w @etabli/plugin-travail      # calculs (vecteur d'or 429,43 €), données, projections, transmission, affichage
```
