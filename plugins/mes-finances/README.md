# Mes finances

Plugin pour [Etable](https://github.com/etable-project/etable) (distribution Quotidien) : l'estimé de la vie courante, jusqu'à quand je tiens, la courbe, les prochains paiements, un ajustement rapide et le recalage sur le solde réel. Il lit Finances (comptes, soldes) et Budget (prévisions) sans les remplacer ; les deux sont facultatifs.

```bash
npm test -w @etabli/plugin-mes-finances      # estimé, courbe, seuil, paiements, précision, données
```
